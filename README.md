# read-aloud

Created in [T3 Code](https://t3.codes).

A [Raycast](https://www.raycast.com) extension for macOS. Select text anywhere, press a hotkey,
and it is read out loud with an ElevenLabs voice, in any language your models support. It can
lower Spotify while it reads.

What it does, its settings, and what it sends to ElevenLabs and TypeSafe are described in
[raycast/README.md](raycast/README.md).

## Install from source

```
cd raycast
npm install
npm run dev    # installs it into Raycast; Ctrl+C when it says "built extension successfully"
```

Raycast asks for your ElevenLabs API key the first time you run **Read Selection**.
