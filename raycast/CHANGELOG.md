# Read Aloud Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Read the selected text out loud with an ElevenLabs voice; run the command again to stop.
- Choose the model per reading from an ordered list, by the languages in the text.
- Reading speed from 1× to 2×.
- Keep recent readings for instant, free replay.
- Optionally lower Spotify while reading.
